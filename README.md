# Teste-MindTech

## Descrição do Projeto
O objetivo deste projeto é desenvolver um sistema de inscrição em uma newsletter fictícia. O projeto será dividido em duas partes: Front-end e Back-end.

## Estrutura do Projeto
- *Front-end*: Utiliza React com Vite para uma experiência de desenvolvimento rápida e eficiente.
- *Back-end*: Construído com Node.js e Express, gerenciando a lógica do servidor e as interações com o banco de dados.
- *Banco de Dados*: SQLite, um banco de dados leve, ideal para protótipos e aplicações de pequeno a médio porte.

## Como Rodar o Projeto

Para executar o projeto, siga os passos abaixo:
 
 cd frontend
 npm install
 npm run dev

 cd backend
 npm install
 npm run dev
