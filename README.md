## Descrição do Projeto
O objetivo desse meu projeto foi desenvolver um sistema de inscrição em uma newsletter fictícia. O projeto será dividido em duas partes: Front-end e Back-end

## Foi utilizadas as seguintes tecnologias nesse projeto:
- *Front-end*: React com Vite.
- *Back-end*: Node.js e Express.
- *Banco de Dados*: SQLite.

## Para executar o projeto, siga os passos abaixo:
 
 cd frontend
 npm install
 npm run dev

 cd backend
 npm install
 npm run dev
